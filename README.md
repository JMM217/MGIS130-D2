# MGIS130-D2
Loan Calculator App.
Data - User types loan amount, interest rate, length of loan and any further information needed, basic numerical input through numbers, % and timeframes.
Processing - Calculate basic properties from user inputted information. Total interest, total repayment, comparison between two sources of information (two loan deals inputted) Formulate plan of action for repayment
Presentation - Clear, user-friendly style aimed at people unfamiliar with complex math. Possible slider to change amount or interest. Avoid lots of numbers and unnecessary details. Comparison charts (as seen on FM), graphs and colour coding to showcase which loans are better value.
